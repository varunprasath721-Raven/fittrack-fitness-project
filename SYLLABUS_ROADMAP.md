# FitTrack syllabus implementation roadmap

## Phase 1 — React Introduction
Home page demonstrates JSX, components, props-ready structure and routing.

## Phase 2 — React fundamentals
Calculator demonstrates dynamic JSX values, math objects, state and event handling.

## Phase 3 — CSS
`src/styles.css` demonstrates global CSS, responsive design and component-oriented sections.
Next phases can add CSS Modules, Tailwind, Styled Components and Bootstrap versions.

## Phase 4 — Lifecycle + Hooks
Dashboard uses `useEffect`, `useState`, `useMemo`, `useCallback`.
Next lesson page can demonstrate `useRef`, `useReducer`, `useLayoutEffect`, Context API and custom hooks.

## Phase 5 — Events and Forms
Workout form covers onSubmit/onChange and controlled inputs.
Next phase adds checkbox, multi-variable forms and validation.

## Phase 6 — Lists, keys, props
Workout list uses `.map()` and stable database IDs as keys.
Components can be split further for explicit parent/child props practice.

## Phase 7 — REST API / CRUD
Django ViewSets expose GET/POST/PUT/PATCH/DELETE.
Axios handles frontend requests and loading/error states.

## Phase 8 — React Router
Routes are included for Home, Dashboard, Calculator, Workouts and Login.

## Phase 9 — Redux + RTK
Redux Toolkit store + auth slice + `createAsyncThunk` are included.
Next phase adds workoutSlice and async CRUD thunks.

## Phase 10 — Django fundamentals
Project/app structure, URL routing, views, templates and SQLite are included.

## Phase 11 — Models + ORM
Workout, Meal and Progress models; migrations and ORM CRUD through ViewSets.

## Phase 12 — Admin
Admin registrations include list display, search and filters.

## Phase 13 — Django Forms / Email
ModelForms are included. Add a contact form + SMTP email page next.

## Phase 14 — Templates / Bootstrap
A Django template is included. Add template inheritance, tags, filters and Bootstrap demo pages.

## Phase 15 — Sessions / Cookies
Add a dedicated Django session/cookie demo page.

## Phase 16 — DRF + JWT
Serializers, ViewSets, routers and SimpleJWT token endpoints are included.

## Phase 17 — Deployment
Render config is included. Frontend can be deployed to Vercel/Netlify with `npm run build`.
